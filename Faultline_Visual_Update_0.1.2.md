# FAULTLINE 0.1.2 — исправления по пяти замечаниям

4 ноября 2026. Обновлены основной проект Unity и отдельная Windows-сборка.

| Замечание | Изменение |
|---|---|
| Меч проходит через мечника | Рукоять совмещена с перчаткой, рука отведена вперёд и наружу, изменены наклон клинка и положение гарды; добавлены пальцы и навершие. Одна поза применяется в сохранённых сценах и при создании героя в бою. |
| Огромные оранжевые прямоугольники в лаве | Убраны плоские оранжевые полосы из мира и арены стража. Сделана бесшовная карта тёмной корки с неровными светящимися прожилками и медленной анимацией. |
| Скучные кнопки | Новая тёмная металлическая поверхность, срезанные углы, двойная окантовка, значки меча/магии/щита, разные оттенки действий, подсветка наведения и отклик на нажатие. Оформление согласовано для боя, меню, диалогов и настроек. |
| Присоединившийся маг отсутствует в мире | После разговора маг покидает убежище и идёт по пройденному героем пути. Останавливается в паузе и диалоге, появляется после переходов и возвращения из боя; новый запуск удаляет спутника. |
| Маленькая последняя цель | Кольцо диаметром 3,2 м, парящий кристалл и подпись «ИСТОЧНИК РАЗЛОМА». Радиус взаимодействия увеличен с 2,1 до 3,6 м. Подсказка проверена с расстояния 3,5 м. |

## Проверка именно Windows-версии 0.1.2

Сборка Unity: успешно, 0 ошибок и 0 предупреждений. Проверялась копия из `Faultline_Windows_0.1.2`, которую содержит архив поставки.

| Проверка | Результат | Журнал |
|---|---|---|
| Эпизод: четыре карты, три победы, финал, все поражения и повторы | 107 PASS, 0 failures, код выхода 0 | `Faultline_012_full_player.log` |
| Спутник: присоединение, повороты, обратный путь, мост, пауза, диалог, переходы, сброс | 19 PASS, 0 failures, код выхода 0; обычная скорость с графикой | `Faultline_012_companion_player.log` |
| Финал: блокировка до победы, реплики, затухание реальных материалов, завершение и сброс | 11 PASS, 0 failures, код выхода 0; с графикой | `Faultline_012_ending_player.log` |
| Ограничение частоты кадров | 60,00 FPS активно / 15,00 FPS в фоне, код выхода 0 | `Faultline_012_performance_player.log` |

В редакторе дополнительно проверены совпадение центров рукояти и перчатки (расстояние 0), 11 положений руки с выборкой клинка (пересечений с торсом/головой не найдено), отсутствие объектов старых лавовых полос и ошибок компиляции шейдера. Подпись финальной цели автоматически обновляет геометрию после холодной загрузки сцены, без принудительного обновления из проверки. Консоль редактора после проверки не содержит ошибок и предупреждений.

Первый прогон движения без графики дал 7 неудачных проверок достижения точек: в неограниченном режиме шаг главного героя оказывался меньше порога движения. Повтор на той же сборке с графическим устройством прошёл все 19 проверок. Для проверки обычной скорости спутника следует использовать команду с графикой, приведённую ниже. Проверка всего эпизода использует ускоренное движение и отдельно проходит без графики. Это не измерение длительности прохождения человеком.

Журналы могут содержать сетевые сообщения Unity Curl DNS; игровых исключений в успешных проверках нет. Процент загрузки GPU здесь не измерялся. Лимит 60/15 из 0.1.1 сохранён; тест FPS программно включает оба режима.

## Повтор проверки

Запускать по одной команде из распакованной папки игры, дожидаясь завершения предыдущего процесса:

```powershell
.\Faultline.exe -batchmode -nographics -faultline-full-qa -logFile full-qa.log
.\Faultline.exe -batchmode -faultline-companion-qa -logFile companion-qa.log
.\Faultline.exe -batchmode -faultline-ending-qa -logFile ending-qa.log
.\Faultline.exe -batchmode -faultline-performance-qa -logFile performance-qa.log
```

Модели и интерфейс исправлены средствами Unity. Новые модели в Blender для этого обновления не потребовались. Использованы рекомендации `craft-game-floors` (character-motion, placeholder-assets, game-shell, visual-scorecard) и `ui-ugui`. Визуальная оценка этого обновления: `Faultline_Visual_Scorecard_0.1.2.md`. Снимки сделаны в работающей игре в редакторе при 1600×900; это контрольные состояния, а не снимки полного ручного прохождения Windows-сборки.

Старые проверки модели боя, аудио и первой поставки остаются в документации с собственными датами и версиями. Полный ручной проход человеком, измерение длительности и тесты на других компьютерах для 0.1.2 не проводились. Исходный диздок и материалы `sources/` не изменены.
